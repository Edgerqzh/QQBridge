# 主动下载、语音转码与稳定性验证

版本 `0.3.0-dev.1`，验证日期 2026-10-30。原生能力仍限定官方 Linux QQ `3.2.34-53644` x64。启用 `QQBRIDGE_EXPERIMENTAL_RICH_MEDIA=1` 后可使用本页媒体接口；[本地登录网页](LOGIN_WEB.md)独立提供扫码入口。

## 主动下载

`get_file` 优先读取缓存，缺失时使用已经接收的真实消息标识调用原生下载接口。只允许当前账号已加入且白名单允许的群、已知媒体标识，不接受任意远程 URL 或本地路径。

```json
{ "action": "get_file", "params": { "file_id": "消息段 data.file 中的标识" } }
```

成功返回 `file_id`、`name`、`size` 和 `base64`。原生 `getRichMediaElement` 在已验证构建中是无返回值的异步派发；项目不把这个返回当成成功 ACK，而是等待实际文件的大小、MD5 与消息元数据一致后才返回内容。没有完整性元数据时明确失败。

相同媒体的并发请求共享一次下载，最多四个原生下载同时进行，默认十秒超时。超时、账号切换或权限撤销会取消等待，并向原生接口发出取消请求；仍未结束的原生 Promise 不释放并发名额。下载失败不自动重试。过期、无权限或服务端拒绝的媒体不会伪装成成功。

媒体索引最多 5000 条，按账号保存于私有 profile，重启后仍可识别文件 ID。索引恢复后仍重新检查当前群成员关系和白名单。索引与下载文件都是账号资料，不进入发布包。单文件输入/输出上限 16 MiB，JSON/WebSocket/IPC 上限 24 MiB；缓存暂不提供自动配额清理。

## 语音转码

发送 `record` 段时，WAV、MP3、Ogg、AMR 等支持的音频会先转为单声道 24 kHz PCM，再编码为 QQ 可用的 SILK；时长从实际音频计算，不依赖调用者填报。直接 SILK 输入仍可保留原数据。

```json
{
  "action": "convert_record",
  "params": { "file": "base64://音频数据", "out_format": "silk" }
}
```

`convert_record` 是扩展动作，返回 `base64`、`format`、`duration_ms`，支持输出 `silk`、`wav`、`mp3`、`ogg`。它只做本地转换，不向 QQ 发送消息。

对已接收语音，可下载后直接转换：

```json
{
  "action": "get_record",
  "params": { "file": "消息段 data.file 中的标识", "out_format": "wav" }
}
```

也接受 `file_id` 参数。成功返回格式、文件名、大小、base64 和毫秒时长。下载与后续转换共享十二秒操作预算。

转码在独立子进程中执行，最多两个任务，超载返回 `1429`；超时终止整个进程树，下一任务仍可运行。解码 PCM 最多十分钟，输出仍受 16 MiB 限制，超限报错而非截断。FFmpeg 只允许管道输入输出和限定的音频容器，不跟随输入中的网络 URL。原始 PCM/WAV 的便携测试不依赖 FFmpeg；完整原生镜像已安装 FFmpeg。手动运行可通过 `QQBRIDGE_FFMPEG_PATH` 指定可执行文件。

## 已完成的验证

| 范围 | 结果 |
| --- | --- |
| 真实未缓存文件 | 通过原生接口主动下载，大小及 MD5 匹配；随后 HTTP `get_file` 命中缓存 |
| 真实语音 | 已转为有效 WAV、MP3、Ogg，MP3 再转 SILK；结果只保存在私有测试环境，没有回发到群 |
| 真实重启恢复 | 保存的账号恢复在线；媒体索引和已下载文件在容器重启后仍可读取，摘要及 WAV 头校验通过 |
| 本地网页 | 用户确认能打开并扫码；二维码路径、失效处理、记住账号与原生自动恢复回调分类已回归 |
| 下载稳定性 | 20 个同时请求仅下载一次；100 次下载夹杂 10 次注入失败均恢复，结束时无活动下载名额 |
| 转码稳定性 | 20 次真实 WAV → SILK → WAV 往返；超时、取消、过载、错误输入后的恢复均通过 |
| Linux 自动化 | 154/154，通过禁用外网、只读源码挂载的容器测试，包含真实 FFmpeg 的 MP3/Ogg/AMR 转换 |
| Windows 自动化 | 153 项通过、1 项跳过；本机未安装 FFmpeg，跳过对应测试；WAV/SILK 及故障恢复实际运行 |

这是短时压力、重启及故障恢复验证，不代表已经完成数天的持续运行测试。账号封控、已过期服务器文件、超出当前账号权限的媒体仍可能被 QQ 拒绝。QQ群内消息发送不属于本轮验证范围。
